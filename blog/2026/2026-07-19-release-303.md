A patch release to the major 3.0.0 release, introducing another tiny performance gain and handling empty values for zero flags. There is also an improvement to help target applications that strip namespaces on resources. This is the last release of the 3.0 version line. 

The 3.1 version anticipates moving the minimum build version to JDK 17, but that is still under internal discussion. We also will move back to the official google/smali fork as development has re-continued over there.

### Changelog

- [[#4138](https://github.com/iBotPeaches/Apktool/pull/4138)] Improve performance (memory reduction) of ResStringPool. (Thanks X1nto)
- [[#4137](https://github.com/iBotPeaches/Apktool/pull/4137)] Improve handling with stripped namespaces. (Thanks Sleeeee)
- [[#4139](https://github.com/iBotPeaches/Apktool/issues/4139)] Fix issue with disassembling empty flag values. (Thanks IgorEisberg)
- [[#4141](https://github.com/iBotPeaches/Apktool/pull/4141)] Refactor tests to xpath usage vs raw DOM access. (Thanks IgorEisberg)
- [[#4133](https://github.com/iBotPeaches/Apktool/pull/4133)] Upgrade `commons-io` to `2.22.0`.
- [[#4131](https://github.com/iBotPeaches/Apktool/pull/4131)] Upgrade `google.guava` to `33.6.0-jre`.
- [[#4146](https://github.com/iBotPeaches/Apktool/pull/4146)] Upgrade `xmlunit-legacy` to `2.12.0`.
- [[#4149](https://github.com/iBotPeaches/Apktool/pull/4149)] Upgrade `gradle/actions` to `6.2.0`.
- [[#4151](https://github.com/iBotPeaches/Apktool/pull/4151)] Upgrade `actions/checkout` to `v7`.
