:::info

The changelog of the upcoming release, subject to change prior to finalization.

:::

- [[#4175](https://github.com/iBotPeaches/Apktool/pull/4175)] Move required build version to JDK 17.
- [[#4155](https://github.com/iBotPeaches/Apktool/pull/4155)] Move to Gradle 9.
- [[#4201](https://github.com/iBotPeaches/Apktool/pull/4201)] Support decoding to an empty folder. (Thanks IgorEisberg & iTrooz)
- [[#4210](https://github.com/iBotPeaches/Apktool/issues/4210)] Fix crash if decoded resource string is empty after escaping. (Thanks iMiKED)
- [[#4177](https://github.com/iBotPeaches/Apktool/pull/4177)] Improve performance and handling of UTF-8 in `apktool.yml`. (Thanks IgorEisberg)
- [[#4205](https://github.com/iBotPeaches/Apktool/pull/4205)] Upgrade `xmlunit-legacy` to `2.13.0`.
- [[#4206](https://github.com/iBotPeaches/Apktool/pull/4206)] Upgrade `gradle/actions` to `6.3.0`.
- [[#4216](https://github.com/iBotPeaches/Apktool/pull/4216)] Upgrade `guava` to `33.7.1-jre`.
- [[#4207](https://github.com/iBotPeaches/Apktool/pull/4207), [#4215](https://github.com/iBotPeaches/Apktool/pull/4215)] Upgrade `gradle` to `9.7.1`.
- [[#4221](https://github.com/iBotPeaches/Apktool/pull/4221)] Upgrade `setup/java` to `v6`.
